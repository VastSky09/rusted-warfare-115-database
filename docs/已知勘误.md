## 2026-11-19：PR #1 合入复核修正

- 修正DPS汇总因空 `domain_conditions` 丢弃全炮位 `condition` 的问题。战斗工程师水下攻击、两级闪电炮塔的条件重新进入单位汇总；不同条件的炮位不默认视为可同时射击。
- 修正研究与对比视图遗漏形态、攻击域和目标限制的问题。飞行堡垒对地攻击需要非飞行状态；鱼雷的ground域不表示可攻击任意岸上单位。展开公式时现在能看到完整限制。

这些修正保持91个对象及既有关系身份、原始战斗事实不变。完整对局效果和未求解能量循环仍不属于已验证结果。
