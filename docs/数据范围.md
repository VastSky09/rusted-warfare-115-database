# 数据范围与数据质量

## v0.2战斗属性扩展

下述A-04范围继续约束原目录与科技关系。新增的`combat.json`由同版本实际生效定义与原生实现复核整理，以原91个ID对齐；不把新增参数的静态核查视为E4对局验证。只发布事实字段、公式和相对文件级来源，不附代码或函数位置。生成输入快照不在公开包内。

## 原目录范围

- 固定输入：冻结版 PC1.15 能力普查 A-04 阶段的 `objects.csv` / `relations.csv` / `states.csv`；公发布目录由脚本确定性生成。
- 只发布P1中的85条及从普通开局（builder + commandCenter）按研究查询器可达的6条P2关联形态。
- 仅保留两个端点均属于上述91条、被A-04标记为可规划、主体为正常object的关系。
- 直接获取关系：建造、生产、同类型内部升级、跨类型升级。
- 分列特殊状态关系：跨类型转化、自动转化、同类型模式请求、过程临时转化。
- 地图预置、特殊开局、隐藏内部组件及弹体链不包含在本次可下载主干数据。
- 不分发原版代码片段、函数位置、私人项目路径、实机日志、单局观测数据、截图和第三方原始版权材料。
- 费用以动作/获取关系为属性；空白表示未记录，不是零元。状态ID表示科技阶段或研究状态，不是自动生成的另一种注册单位。
- 数据E1/E3等研究证据不能自动升格为E4。具体条件和局内可用性仍以游戏原生实际状态为准。
- 没有默认复制原版帮助菜单，因为已观察到部分价格过时，且存在未启用的INI备用实现。
