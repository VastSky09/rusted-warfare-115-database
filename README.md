# 铁锈战争 PC 1.15｜原版单位与科技资料库（v0.3 多视图与战斗属性）

## Web 视图

`index.html` 保留原版界面并作为默认入口，顶部可进入三个研究视图：

- **紧凑查询台：** 目录与获取关系并排，支持中文名、内部名和常用简称搜索。
- **科技路径浏览：** 以当前对象为中心，查看上游来源、下游去向和完整阶段记录。
- **战术对比工作台：** 最多四个对象并列，先比较获取方式，再按需展开战斗属性与条件 DPS。

三个研究视图位于 `workbench.html`，切换时保留当前对象；返回原版资料库可继续查看该对象的完整战斗属性和状态。所有视图默认收起战斗属性。页面与数据均可离线使用，`python tools/build_page.py` 会从同一份 CSV/JSON 同时更新首页和 `ui/data.js`。

## 战斗属性扩展

在原91对象、212条科技关系、12条形态关系上新增 `data/combat.json`，补充生命/护盾与回复、视野、能量、通行、前进/倒车、转向、真实炮位和状态资料。打开原 `index.html` 即可查看，不需要联网。

DPS是带公式与条件的派生值：冷态/满转、逐发预热、共享能源上界、范围中心命中上限、削盾与穿入本体分别展示。能量循环未求解时不填写实际长期DPS；未知值不伪装成0。详见 [战斗属性说明](docs/战斗属性说明.md)。静态数值整理不表示已完成全部游戏内对战验证。

页面可由 `python tools/build_page.py` 从CSV和战斗JSON重新生成；公式回归用 `python -m unittest discover -s tools -p "test_*.py"`，数据及交互桩分别用 `python tools/check_combat.py`、`node tools/test_page.mjs` 检查。交互桩不包含浏览器排版渲染。

**只包含独立整理的事实性表格、文字与自制展示工具；不包含游戏客户端、原版JAR、INI原文件、解包贴图、反编译源码、私人录像或Agent策略代码。**

## 项目介绍
从冻结的PC 1.15原版研究成果（A-04，有条件通过）导出，帮助玩家与脚本开发者查询原版单位、生产、建造、升级及主要形态转换。游戏名称及相关知识产权归原权利人，本资料库是非官方研究整理，且与游戏开发商无官方关联。

**本版收录：91条对象档案（85条P1标准内容、6条与常规科技链相关的P2形态）；212条状态敏感的建造/生产/升级关系；12条相关形态/模式转换关系。**
这不是178条全部对象或460条完整研究关系的原封不动发布：旧Java被替换类型、禁用/编辑器专属、地图初始放置、实验性内部生成与其他边缘项暂不发布。

## 如何使用
- **浏览器：** 直接打开 `index.html`，无需部署服务或联网。
- **表格：** `data/units.csv` 是标准单位与关联特殊形态；`data/tech_relations.csv` 为科技主干；`data/transformations.csv` 为相关转换。
- **主干图：** `figures/tech_overview.mmd` 是Mermaid流程图源码，可粘到支持Mermaid的平台查看；仅绘制代表性分支，**完整关系以CSV为准**。
- 未附原生 `.xmind` 文件。工作区另有未验收的FreeMind `.mm` 草稿，不包含在公开压缩包中。

## 重要解释
- **费用因来源、状态和动作而异**。`units.csv` 列出的只是已研究的获取费用候选，单一价格不是所有获取方式的一般成本。
- 同一个生产动作在T1/T2来源状态下可能各占一行，属于状态敏感关系，不是两项独立单位。
- 当前资料只证明**原版研究记录与相关有界实验**，不是全部E4真实对局验证，也不是任何时刻都能合法或成功执行的实时命令表。
- 原版帮助菜单可能包含旧版本数值。例如本版研究为火炮机甲1400$、两栖飞机2000$；以实际生效实现与动作费用为准。
- 研究证据仍有未知项，本公开预览不包括未独立核验的长尾条目。

## 数据表统计

## 数据来源与核验范围
- 数据根据冻结的《铁锈战争》PC 1.15 原版独立研究整理，采用 A-04 阶段的固定数据快照。
- 整理过程中区分原版注册对象、科技状态与实际生效规则；不公布内部研发仓库、人员账号及本地版本标识。
- 原版解释依据：冻结PC1.15与研究样本；本公开包只提供整理结果，不分发原版可执行文件。
- 研究版本、筛选规则与当前验收边界详见 `docs/数据范围.md`。
